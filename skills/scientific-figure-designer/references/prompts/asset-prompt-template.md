# Research Asset Generation Prompt Template

Create a standalone **illustrative scientific object** only, not a finished figure and not experimental evidence.

Scientific object: `{APPROVED_ENTITY_NAME}`.
Required visible features from approved source: `{FEATURES_WITH_SOURCE_IDS}`.
Role in this figure: `{ILLUSTRATIVE_ROLE}`.
Art direction: `{DOMAIN_STYLE_FAMILY}` (consistent with all other assets in this figure).
Composition: subject centered within own cell, complete silhouette, no clipped structures, intended placement `{TARGET_ASPECT}`. Transparent background when supported.

**Absolutely no visible text**, no numbers, no annotations, no arrows, no axes, no scales, no logo, no QR code, no decorative scientific object not present in the approved entity list. Do not depict measured changes, microscopy results, fake blots, pathway activations or treatment efficacy. Preserve the scientifically required anatomy or system component representation. If unable to represent requested scientific structure, return a candidate for review; never invent.

Asset must pass human scientific review and rights checks before becoming production-approved.
