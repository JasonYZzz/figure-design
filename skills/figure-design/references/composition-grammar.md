# Scientific Composition Grammar

## Model the page as communication roles, not cards

Start with one sentence a reviewer should understand, identify 1 main visual anchor, infer true sequential vs parallel/feedback structure from FigureContent, allocate informative drawings only where they explain a scientific object or measurement. Scientific figure layout must reflect research intent, not force all entities into equal boxes.

Design grammar: `primary` + zero to three `modifiers` + zero or more `asset_treatments` + explicit `science_constraints`. Ref Inspired by PPT Master's P/M/A pattern families, not a copy of its 90 pattern descriptions.

### Suggested primary grammars

- `top-overview-multi-lane`: research subjects / input conditions on top, parallel or staged study panels below. Great for four aims / biological research.
- `center-hero-side-support`: a visually dominant causal or method center path; methodological inputs on left, validations/risks on right; bottom outputs.
- `annual-stage-timeline`: years/stages along a readable axis; use dimensional rhythm, anchored pictograms, varied weight instead of four full-width text cards.
- `macro-micro-mechanism`: organ → tissue → cell/molecular pathways, sourced relation lines.
- `fork-merge-validation`: parallel research arms converge on shared readouts or hypothesis validation.
- `matrix-plus-flow`: comparative groups or controls beside task flow.
- `funnel-evidence`: screening → mechanistic analysis → validation with scoped evidence.
- `hub-spoke`: one system with genuinely nonsequential satellites.
- `network-overlay`: exact scientific edges and labels drawn on approved background imagery.
- `comparative-panels`: side-by-side equal-scaled scientific comparisons.
- `experimental-apparatus`: source-authenticated structure and measurement relation.
- `minimal-text-graphical-abstract`: one focal visual, few trusted labels.

### Useful modifiers (conditions of use)

- `zoom_callout`: only if input actually discusses cross-scale or local detail.
- `organic_cutout`: high-quality independent asset, no scientific distortion.
- `frame_breakout`: main object may cross an ornamental boundary but never a scientific or text safe zone.
- `directional_scrim`: only when text readability is improved.
- `asymmetric_weighting`: favor one key process, maintain peer comparability where needed.
- `nonrectangular_region`: shape is meaningful and does not reduce text capacity.
- `registered_layer`: original coordinate system preserved across base and overlay.
- `varied_band_rhythm`: alternation motivated by stages and density.

### Hard design gates

- Every visible exact label has an independent slot and real font sizing; never shrink below the selected output's legibility floor.
- No label may be silently shortened; approved abbreviations reside in FigureContent.
- All edges have source and target IDs, type (sequence, parallel, measurement, tests, activates, inhibits, feedback...), condition, evidence state and source evidence; never infer an arrow from proximity alone.
- Avoid adding decorative DNA, molecules, microscope, mouse, charts, bars or fabricated blots when absent from document.
- Preserve status: proposed work is labeled proposed; never draw invented measured result.
- Reject a composition if capacity or connections cannot fit; rank second candidate or split figure with explicit user's desired output.

## Choosing a candidate

Use the source-bound reading task to choose between a system overview and an evidence-first comparison. Bind representative assets and run preflight on both plans. Compare the rendered candidates at the target width and record what a reader learns from the shared objects, experimental contrasts and illustrations. Keep label and edge integrity as hard constraints.
