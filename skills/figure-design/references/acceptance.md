# 软件验收与科研交付边界

当前版本 `1.2.0` 的可运行功能以 standalone-workflow.md 和 CLI --help 为准。

软件验证包括：原有 17 项回归、独立内容/参考/素材/状态/数据检查、Chromium 集成测试、12 个构图入口与 4 个附加压力案例，以及解压安装后的完整流程。测试使用虚构研究内容；不能据此宣称真实科研抽取正确率或专家审美偏好。

每次出图必须检查：原文绑定、研究状态、必需实例和关键关系、实际文字和字体、文字越界/重叠、连线避障、素材权限 metadata、输出 hash。任何机器错误阻断正式导出。数学/字形/路由不支持要报错，不能用空白或近似代替。

机器门禁通过后的状态仍是 review_required：Codex 审查语义与画面，用户真正验收后才能使用 hash 绑定的接受记录。人类标签金标、资产版权真实性、学科专家盲评、线上供应商实际计费能力是外部验证，不能由脚本或模型自签。

30 图审校入口是 refs-review 生成的 HTML 和 annotations.json。填写真实审核者、分类、观察、推断及 attestation，再 refs-annotate；未完成时保持 auto_proposed，不阻止把候选当作待核对设计线索，但禁止宣称为金标。

自动导出的 draft ZIP 可供审阅；final ZIP 要求该 render_hash 的完整人类接受记录。旧图与未知模型请求不自动覆盖或重提。
