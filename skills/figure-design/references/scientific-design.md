# 科研分析与构图设计

科研分析使用本包资源。新建图文混合科研图时，由当前 Agent 调用本会话的生图技能制作插图。方法参考了本地 nature-figure 的科学主张与面板分工、nature-proposal-writer 的证据表与论证图，以及 PPT Master 的内容先于版式设计原则；这里是适配本产品的独立实现。

## 从来源到设计简报

完成 ingest 和 FigureContent 后运行：

```bash
python scripts/figure.py research-brief --content /工作目录/content.json --sources /工作目录/sources/HASH/source.json --out /工作目录/research-brief.json
```

程序先重新校验原件与精确摘录，再整理任务、正式标签、来源和关系。输出的 `design_decisions` 是待填写工作表；不能把空字段、机器生成的结构或非空字符串当作科学审查通过。

宿主 Agent 读取摘录，完成以下设计判断，并保留具体来源 ID：

1. **中心问题或有证据支持的结论**：研究计划写“拟检验什么”，结果图写“实际支持什么”。未知项保持未知；不把机制假说写成已经证明。
2. **证据分工**：为各面板确定独立问题、证据作用和必要性。对象/方法介绍、主证据、对照、验证各有职责；只有改变内容契约并重新审阅后才能合并或删去任务。
3. **替代解释与条件**：列出原文出现的对照、适用范围、否定、单位和不确定性。原文没有的信息标为待补，不能代填样本量、统计结论或因果关系。
4. **视觉主次**：明确 hero_owner_id 与阅读顺序；主视觉面积服务于研究问题，不因先选了母版而改变科学含义。同一研究对象在所有区域保持一致颜色含义。
5. **参考选择**：检索少量原图，记录哪些布局、层级或图文关系可以借鉴。不得从参考图继承实验事实、原图像素许可或科学连接。
6. **图文分工**：在 `visual_concept.route` 记下选用路线。在 `depictions` 逐项记录 owner ID、source IDs、描绘对象或方法、该图解释的关系，以及素材来源或绘制方式。优先为主对象和关键方法留出独立视觉区域。若合适的图形会误导读者，或依据与可用素材不齐，在 `fallback_reason` 写明原因及影响。

简报的 source_content_hash 必须对应当前 FigureContent。源内容改变后重新生成新版本，不沿用旧简报中的结论。设计决策由 宿主 Agent 应用于 plan 的区域位置、视觉优先级和获准素材；它不是另一套事实来源，也不是自动科研推理器。

## 主图与实验的对应关系

- 在 `design_decisions.main_paths` 写出各条主路径的起点、交接物、操作、终点和来源。原文允许直接访问、并行处理或可选维护时，给这些路径留出独立走向。暂时遮住案例，读者仍应能回答标题里的系统问题。
- 对有实验结果的面板，在 `evidence_scope` 写明改变的条件、保持的对照、读数与单位、支持的对象或路径，以及推广边界。先把图上的实验连线读成一句完整主张。多环节同时改变时，把结果配给这一组操作；只有实验单独改变某一环节时才将效果归给该环节。原文有适用范围的反例时，放在对应结果旁。
- `composition.relation_review` 列出图上没有原生连线的实体，以及实际绘出的检验、测量和支持关系。对照成图检查孤立实体是有意的背景说明、素材内已画的关系还是漏画。核对证据连线两端的画面和文字与实验问题是否一致。未设计检验连线的结果可用指向同一机制的明确标题或图例挂接。

## 对照两个候选

保持内容和关系不变，比较主问题是否清楚、证据是否完整、主要区域与验证区域是否有适当层次、条件文字是否装得下、连接是否容易理解。使用实际 preflight 验证文字和路由，再查看完整 PNG。

被数据或来源支持的关系由程序精确绘制。机制形态、对象真实性和图像内部文字需要视觉/科学复核。若图片缺失，可以交付有明确缺口的结构草稿，不绘制虚构实验结果。

## 本地资源完整性

素材注册和最终 SVG 编译均调用随包的 `scripts/vendor/ppt_master_svg_resources.py`。它检查嵌入 SVG、CSS url、外部样式表和资源引用是否完整包含在文件内；同时保留本项目原有的 SVG 元素/属性限制。字体和获准图片实际嵌入输出，不依靠外部网址显示。

该检查不判断科研正确性，也不能替代对 raster 图片内部文字和内容的审阅。第三方代码许可与源文件 hash 见 [本地来源说明](../third_party/README.md)。
