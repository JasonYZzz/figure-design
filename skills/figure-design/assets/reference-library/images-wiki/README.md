# 参考图知识导航

打开 [Markdown 索引](index.md)，从研究任务进入构图原则，再按证据区域查看单图分析。下载项目或解压安装包后，可在浏览器打开 [离线导航](index.html)，按参考编号、领域、构图方式或观察关键词筛选。

原图保存在相邻 `images/` 目录。公开包携带分析页，页面会提示原图无法读取。已有本地图集时，可用 `refs-search --images <目录>` 按 SHA256 核对来源。

知识页、检索索引和构建记录由 `refs-build` 生成。图像观察、更新流程和校验命令见 [参考知识工作流](../../../references/reference-knowledge.md)。分层来源、交叉链接和本地索引的设计参考 [LLM Wiki](https://github.com/nashsu/llm_wiki#what-we-kept-from-the-original)。
