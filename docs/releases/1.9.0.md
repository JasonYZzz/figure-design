# Figure Design 1.9.0

- 上传设计参考后直接进入简报和规划。缩减包可沿用 Wiki 结构描述，图库不可用时可用领域主题。
- 参考特征绑定区域、共享底板和关系。支持部分黑白色样、语义连线色和随主题生成的原创 SVG。社会政策预设的赭色按正文对比度要求加深。
- Chromium 检查页脚与关系标签的碰撞，并在指定显示宽度测量字号和溢出。审阅记录随渲染摘要校验，必需的参考组发生偏离时阻断最终导出。
- 源文件包一次写入来源、资产、审阅和授权附件。清单覆盖包内文件，经核对的 PDF 异常页转录可与原件一起复验。

使用 [独立工作流程](../../skills/figure-design/references/standalone-workflow.md) 安装。保留 1.8.0 历史包及历史渲染目录，1.9.0 使用新目录渲染。真实科研图的内容和视觉验收由审阅者确认。
