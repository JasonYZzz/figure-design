# 1.6.0 纯文字构图与安装包

- 纯文字架构图和技术路线图由原版 Diagram Design Skill 编写 HTML。删除本项目旧文字渲染，`diagram-export` 直接调用上游检查和导出。
- Skill 与 CLI 默认 `text`。`plan --mode text` 返回交接文件，`plan --mode mixed` 生成本文档的图文计划。
- 图文构图沿用参考图结构，主题按内容制定并校验文字对比度。实际色值记录在质量报告。
- 轻量包收录原版 Diagram Design Skill、模板、规则、示例和许可证。私用包另附全部 161 张科研参考原图，逐张校验 SHA-256。

在 DSH 中打开对应项目，运行 `doctor` 确认 1.6.0，再从原内容重新规划。命令详见 [独立工作流程](../../skills/figure-design/references/standalone-workflow.md)。
