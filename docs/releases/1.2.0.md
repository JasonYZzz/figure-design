日期：2026-11-17。运行源码、第三方复用模块、字体、索引和操作说明全部包含在 Skill 内；不从 GitHub 下载/执行源码，也不从用户本机的 PPT Master 或 nature skills 路径动态导入。

## 实际整合

| 本地参考 | 采取的动作 | 当前项目位置 |
|---|---|---|
| 用户下载的 PPT Master `resource_paths.py` | 复制实际使用的 SVG 资源闭包检查函数与常量，保留 MIT 版权/许可，去掉不使用的 PPT 路径处理 | `scripts/vendor/ppt_master_svg_resources.py` |
| PPT Master shared-standards-core | 分析资源完整包含、内容先于版式的原则；没有整套搬入 PPTX 工程 | 素材注册与最终 SVG 编译调用本地检查 |
| nature-figure figure-contract / multipanel-evidence-architecture | 参考主问题、证据主次、面板职责、条件与不确定性的设计方法，独立实现适配逻辑 | `scripts/figure_research.py`、`references/scientific-design.md` |
| nature-proposal-writer evidence-table / argument-map | 参考证据映射和论证结构，整理精确来源工作表 | `research-brief` CLI 与 Codex 设计流程 |

以上路径均以 [Skill 目录](../../skills/figure-design/) 为根。实际分析的上游文件、hash 和复用方式见 [sources.json](../../skills/figure-design/third_party/sources.json)。PPT Master 副本以 [MIT](../../skills/figure-design/third_party/ppt-master/LICENSE) 使用；nature 部分没有复制源码/整套提示词或来源不清的样例图。

新 research-brief 命令先运行原件/精确跨度校验，输出任务、标签、来源和关系映射，再由 Codex 补充科学问题、主视觉、面板证据角色、对照和参考选择。程序不自动填科学结论、不提升研究状态、不假装通过人审。

## 本地化边界

- 当前架构说明改为链接本项目文件；字体来源记录改为本地文件名与 hash，实际字体本来已随包。
- 占位的 Schema `$id` 改为不可下载的 URN；标准 Schema dialect 和 XML namespace 保留，因为它们是格式标识。
- 素材注册及最终 SVG 编译调用本地 vendor，检查嵌入 SVG、CSS url、外部样式表及资源引用。继续执行原有元素/属性限制。
- implementation_hash 递归覆盖 vendor 代码，第三方清单记录本地副本 hash；维护检查阻止代码混入 GitHub 源码地址或开发机绝对路径。
- 历史归档中的出处不参与运行；CI Actions 是可选开发自动化，用户安装包不包含 CI。
- 本次未下载整套无关仓库，也未引入 PPTX、在线搜图或自动更新器。普通 Python 包与 Chromium 仍是安装依赖；当前 ZIP 不是操作系统运行环境镜像。
