# 1.8.0 DSH 插件与参考图库审查

## DSH 规范核对

| 项目 | 本项目的实现 | 核对结论 |
| --- | --- | --- |
| 安装单元和加载 | `dsh.bundle.patch` 指向随包 YAML。`insert` 用 npm 包名加载根导出 | 与官方 Bundle 模板、`dsh-context` 和 `dsh-image-gen` 一致 |
| 宿主入口和生命周期 | ESM 导出 `name`、`inject = ['skills']` 和 `apply`。`ctx.skills.register()` 管理注册，`resourceBase` 指向包内 Skill | 使用官方 Skill 接口。`/dsh-figure-design` 可与用户目录下的 `/figure-design` 并存 |
| 展示和兼容 | 中英 locale、导出的图标、README、`engines.dsh`、`engines.node` | 有独立的插件管理卡片和版本边界。Python 依赖及 Chromium 由使用者配置 |
| 分发 | `make package-dsh` 同步 Skill 版本和公开资源清单，检查最终 tarball 的入口、补丁、元数据、许可证及 payload | 预构建 `.tgz` 是安装单元。`dsh-context` 的 `./client` 和 `dsh.client` 用于它的 Web 面板，本插件在宿主提供 Skill |

参考 [官方 Bundle 规范](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/preset/agent-preset/skills/dsh-doc/references/host-plugin.md)、[Skill 接口](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/skills.md)、[dsh-context 清单](https://github.com/bowenliang123/dsh-context/blob/main/package.json)、[dsh-image-gen 清单](https://github.com/shanliuling/dsh-image-gen/blob/main/package.json)。

## 座舱路线图复盘

用户的原任务用了独立安装的 1.7.0 Skill。默认 `python3` 检查失败后改用现有虚拟环境。会话检索到 `ref-008`、`ref-131`、`ref-004` 和 `ref-007`，简报保留前两张，记录了后两张的排除理由。渲染器完成了原文跨度核对、23 个正式文字实例、5 幅素材放置和 3 条年度关系的检查。

1. **构图迁移停在主题说明。** `ref-008` 的顶部主视觉讲清对象之间的关系，中段机制和旁路另有职责。`ref-131` 把方法、图和阶段内的传递合在同一区域。原成图可读，但四年重复同一种左侧图标与右侧正文卡片。座舱示意与年度插图的视觉面积接近，插图中的符号多由相邻正文解释，读者仍需先读长段才能理解不同阶段如何工作。
2. **按年度排版弱化了科学主线。** 两个核心问题是三类不确定性如何传播、按动作后果校准能否降低误执行。原图把三路证据放在第 2 年正文，把两项检验判据集中到页底。建议让第 2 年的示意直接标明意图、状态和回执三路如何进入传播追踪，第 3 年的图明确检查前置条件之后才进行风险校准。评测条款仍以原文为准。
3. **预检只量了排字，漏了最终字形。** 首次 `preflight` 通过，随后正式 SVG 的 `page_title` 上界越出区域。一次增高又与 `cockpit-scene` 重叠。1.8.0 的预检渲染同一份 SVG，量 `getBBox()`、检查文字精确性和重叠，再给出通过结果。预检保留在内存执行。
4. **从“检索到”推进到“实际用了什么”。** `plan --brief` 校验内容指纹、选中的参考及区域，并将具体迁移动作写入 `selection.json`。只有明确选用的参考才调整初始候选顺序。`asset_fraction` 允许主视觉和支持插图使用不同的图文比例。实图仍按目标使用尺寸审查。
5. **印刷图曾触发像素差阈值。** 上次把 2× 截图缩回 1× 后，最大通道平均差为 2.56，高于脚本设定的 2.0，随后交付记录改用肉眼复核。缩放与抗锯齿会改变像素。跨倍率验收宜核对同一 SVG 的文字、资源、画布尺寸和元素位置，再打开实图核对裁切与可读性。

## 活跃图库

首轮逐张查看 161 张总览，按可读性、关系清晰度和可迁移价值移出 42 张。第二轮放大复查分辨率、字形和关系线较弱的候选，再移出 9 张，最终保留 110 张。清理同步覆盖原图、catalog、逐图分析、相关链接和知识代。保留全部 9 条构图原则及既有分类覆盖，各原则仍满足自己的来源规则。裁定为模型编辑审查，原图复用许可仍需单独核实。

| 移出原因 | 数量 | 示例 |
| --- | ---: | --- |
| 近似布局或配色变体 | 11 | `ref-134` 与 `ref-075` 同为四章节方法侧栏，留一张。`ref-159` 与 `ref-145` 同为体外与体内阶段变体 |
| 空白或占位模板 | 10 | `ref-030`、`ref-034`、`ref-073` 缺少可核对的正式图文层级 |
| 层级或对比度偏弱 | 16 | `ref-032`、`ref-040`、`ref-052` 的浅色小节点密集，已有更清楚的对应构图 |
| 过密且有可替代样例 | 5 | `ref-130` 的七列在缩小后难以辨读，保留阶段与主次更明确的 `ref-131` |

第二轮移出 `ref-002`、`ref-006`、`ref-014`、`ref-065`、`ref-069`、`ref-108`、`ref-117`、`ref-123` 和 `ref-136`。`ref-064` 尽管分辨率有限，仍可辨认条件分支和错误回接，并且是该原则的独立来源之一，因此保留。

本地原图字节从 29,564,171 降到 21,541,876，减少约 27.1%。本机工作区的 `build/reference-curation/` 和 `build/images-wiki-audit/` 保存两轮裁定与历史库。公开 ZIP 和 DSH 包携带导航、分析和索引，参考图原件随本机私用 ZIP 分发。
