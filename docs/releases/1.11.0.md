# Figure Design 1.11.0

图文路线图支持给原生箭头标注与原文绑定的操作。已有计划继续使用默认的关系标签。简报加入主路径与实验范围，质量报告列出已展示但缺少原生连线的实体，以及检验、测量和支持关系的实际端点，供制图者按原文审阅。参见[科研分析与构图](../../skills/figure-design/references/scientific-design.md)和[运行契约](../../skills/figure-design/references/figure-pipeline.md)。

## 安装兼容说明

DSH 清单统一采用 `^0.2.1-rc.3`，安装文档注明验证使用的 npm CLI 与桌面宿主 `0.2.2-rc.5`，以及同版本重装步骤。Python 要求按当前渲染依赖修正为 3.11+。此次修订沿用 1.11.0。详见 [DSH 插件说明](../../plugins/dsh-figure-design/README.md)和[独立安装说明](../../skills/figure-design/references/standalone-workflow.md#安装)。
