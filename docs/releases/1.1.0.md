# Scientific Figure Designer 1.1.0 交付记录

日期：2026-11-17。产品是独立安装到 Codex 的 Skill，代码位于 [.agents/skills/scientific-figure-designer](../../skills/scientific-figure-designer)。Codex 负责理解文档、查看图像与设计；随包程序执行可验证的本地处理。无需另建网站或 DSH 服务。

软件功能已交付且通过本机安装后复验。**原计划的全部科研、视觉及供应商验收尚未通过**：没有提供真实科研文档做最终端到端验收，没有实际人类金标/专家盲评，也未实际调用付费生图供应商。下面区分功能实现与验收证据，避免把测试图当作科研终稿。

## 安装包与使用

- `build/releases/1.1.0/scientific-figure-designer-1.1.0-private.zip`：42,154,969 字节，211 个内容文件及 hash 清单，包含 161 张原参考图和 Noto CJK 字体。
- SHA-256：`7c8a5d4354fe1b7f6e2f2cf5909efb22cd5371c2c4ade665acf5a1139b501310`。
- [安装及完整操作说明](../../skills/figure-design/references/standalone-workflow.md)：解压后运行 `scripts/install.py --to <skills父目录>`，再安装 Python 依赖及 Chromium，运行 doctor。安装器检查全部文件 hash，拒绝覆盖现有 Skill。
- 当前项目直接调用 `$scientific-figure-designer`。无需重新复制源码；若当前会话缓存旧描述，可在当前项目新会话调用。

可直接向 Codex 提交：

> 使用 $scientific-figure-designer，根据这份研究方案制作技术路线图。先检索随包参考库并查看相关原图，比较中心主视觉与多泳道两个构图，保留实验条件，输出 SVG、PNG、PDF 与质量报告。

参考图通过 SQLite 候选标签/观察描述检索，返回原图相对路径；Codex 查看命中的原图，迁移构图、层级和样式。它不是模型训练结果，也不赋予原图像素复用许可。全部 161 张图已做缩略图级粗粒度观察，状态为 auto_proposed、许可 unknown。可在 `build/runs/gold-review/review.html` 逐张审查；没有自动签署人工通过。
