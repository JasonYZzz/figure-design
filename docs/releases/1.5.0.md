# 1.5.0 模式选择与 HTML 导出

- `plan --mode text --diagram-type architecture|roadmap` 生成纯文字架构图或技术路线图。项目内完整复制本地 Diagram Design 源码快照，渲染复用其 HTML 模板，构图参考其对应图型规则。
- `plan --mode mixed` 生成带插图的科研图，预检和渲染要求至少绑定一份获准素材。
- 两种模式均交付 SVG、PNG、独立 HTML 和质量报告。HTML 自带字体和素材，可离线打开。旧渲染包导出时从原有 SVG 生成 HTML，PDF 继续可作为输入文档。

具体命令、兼容选项和产物清单见 [独立工作流程](../../skills/scientific-figure-designer/references/standalone-workflow.md)。
