# Figure Design 1.10.0

2026-11-19。活跃参考库共 111 张，包含 99 张旧图、2 张用户供图，以及重做的 10 张计算机路线图。参考记录均为模型审阅。

## 原图复查

对全部 110 张检查解码、尺寸、SHA-256、dHash 和整图总览。对小尺寸、密集、疑似占位图按原始像素查看细节。按实际文字和线条可读性裁定，例如保留 440 × 790 的 ref-024，其设备图和阶段标签仍清楚。保留 ref-064 的原因是正常处理与重试出口有具体对应。移出的原图可从本地升级前快照或历史私用包恢复。

| 文件 | 移出原因 |
| --- | --- |
| ref-021 | 530 × 700 内压入多组散点图和参数表，辅助轴标与参数过小 |
| ref-033、043、044、047 | 分析分支沿用 XX 或同类占位文字 |
| ref-039、049 | 空任务框、无标签判断和回线难以确定具体操作 |
| ref-051、054 | 成组清单留空或沿用“可能性1”等占位 |
| ref-126 | 645 × 360 内横排五栏，微型图的坐标与子标签过小 |
| ref-131 | 微型曲线、阶段子标签和部分不完整文字影响阅读 |

两份附件与旧库逐张比对 SHA-256 均无相同文件。RSV 路线与软件风险路线的最近 dHash 距离分别为 15/64 和 19/64；目视核对构图后均以原始字节入库。软件风险图局部标签重叠，知识页保留了这项限制。图库用它们的行列组织和矩阵交接作为设计参考。

## 原创计算机路线图

同版撤下首批 10 张计算机示例。用内置图像生成工具重新绘制 10 个主题，按设备、对象、中间表示与验证之间的对应关系筛选。结构光与织物分割可用于学习同一对象跨阶段的表达。

| 入选图 | 可借鉴的图形表达 |
| --- | --- |
| 结构光三维尺寸检测 | 同一法兰贯穿条纹、相位、点云和截面，再以截面说明孔径与端面检验 |
| 织物表面缺陷分割 | 同一处断纱从布幅逐级放大至像素标注，预测结果拼回整幅，右侧并排展示误检与漏检 |

缓存、声学检测、双目深度、文档问答、点云配准、机器人建图、流计算检查点及工业 CT 的重绘稿按用户要求也已入库。每张有可迁移的局部与技术限制，检索结果和知识页均显示。可从[离线图库](../../skills/figure-design/assets/reference-library/images-wiki/index.html)按中文题名查找各图。

## 离线空间图例

图文模式新增 `legend-3d`。本地 Three.js 正交相机和 SVGRenderer 将可编辑 JSON 场景投影为透明 SVG。随包提供特征层级、稀疏体素、分层存储三组场景。安装后的渲染使用现有 Chromium。图例完成内容绑定和素材审阅后可进入现有排版与导出流程。[使用方法与几何限制](../../skills/figure-design/references/threejs-legends.md)

## 混合图生成与验证

设计简报增加具体对象在不同阶段的变化和结果图形两项。质量报告按结果归属列出实际登记的证据图和示意图。针对智能体记忆个案，采用同一地标的错记、校正和后续行动来讲机制，两幅同刻度组内比较图与一张三组结局表呈现结果。

## 同版无损 WebP

私用包的 111 张参考图均为原尺寸无损 WebP。每张按原始图像解码后的 RGBA 字节和分发文件 SHA-256 校验。原文件哈希继续用于身份及既有分析。PNG 容器内的签名在原始文件上核查。JPEG 的参照物为该 JPEG 的解码像素，改格式不会恢复有损编码前的细节。轻量包提供索引和分析。

```sh
.venv/bin/python scripts/compact_references.py --all-webp --out build/compact-reference-library
```

同一批 111 张的原文件共 41,244,342 字节，WebP 共 22,702,092 字节，减少 45.0%。私用 ZIP 为 37.03 MiB。111 张的解码 RGBA 均与原件一致。Chromium 的 sRGB 画布复测中，110 张逐像素一致，ref-068 的半透明合成有 19,833 个像素产生舍入差异，最大通道差为 3/255。
