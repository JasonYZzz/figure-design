# 1.4.0 图文路线图与项目结构

- 文档生成入口先填写图文构思。可描绘的研究对象和关键方法优先使用图文合成；本地原创 SVG 和获准素材沿用同一资产审核及绑定流程。
- 自动布局现在保留 `plan` 的 `--route` 和 `--variant`。CLI 默认仍支持 `text_structured`，现有纯文字及关系图可继续运行。
- 预检和质量报告增加 `composition.route` 与 `composition.asset_placements`，可以核对哪份素材落在哪个区域。科学与视觉审阅仍通过实际 PNG 完成。
- 统一项目、Skill 和发行名称，补充安装、生成、排查和维护说明。

## 本地验证

40 项测试与 16 个构图基准通过。离线图文样例覆盖缺素材拦截、素材放置、SVG/PNG/PDF 渲染及待审导出。轻量和私用 ZIP 均通过隔离安装验证。私用安装保留 161 张原图的 SHA256。旧项目路径通过本地链接兼容。
