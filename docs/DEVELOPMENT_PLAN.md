# 开发计划与当前状态

当前版本 **1.11.0**，项目和独立 Agent Skill 统一使用 `figure-design`。唯一源码目录是 `skills/figure-design/`。用户通过独立安装包或 DSH 插件包部署 Skill。

来源绑定的箭头动作和证据范围审阅见 [1.11.0 交付记录](releases/1.11.0.md)。图库复查与离线 Three.js 图例见 [1.10.0 交付记录](releases/1.10.0.md)。

## 1.9.0 图文生成

- 上传参考直达简报和规划器，上传路线不访问图库。结构迁移记录沿用到预检与成图复核。
- 支持参考分区取色、灰阶保留、八组十六套配色及原创 SVG 主题变量。
- 共享底板可跨多个排版区，参考目标可绑定区域、组和关系。Chromium 测量页脚、连接标签及目标显示尺寸。
- 视觉审阅与渲染摘要绑定，质量报告随包包含审阅。PDF 异常页可用 Poppler 重提或以核对后的文本建立原件绑定快照。
- 实施批次与未关闭的人审项见 [开发清单](development/BACKLOG.csv) 的 FD19 记录。

## 已交付

- 文档内容/来源绑定、候选参考库检索、构图规划、四条渲染路线、精确文字/连接、素材管理、改字和导出。
- 仓库结构统一、111 张参考图与索引集中管理、可迁移的完整/轻量 ZIP、安装完整性检查。
- 本地软件测试与构图基准；具体数量、环境和输出见各版本记录。

- 111 张原图独立分析、9 类任务导航、中文结构检索、brief/plan 衔接、可恢复知识构建及检索评测工具。
- 文档路线图默认先设计图文分工；自动候选保留 route 和 variant，预检和质量报告列出素材绑定。
- `text` 和 `mixed` 两种模式统一交付 SVG、PNG、离线 HTML 和质量报告。纯文字复用随包 Diagram Design 的架构与路线图能力。
- 纯文字交给原版 Diagram Design，图文使用可校验的语义配色。轻量包收录完整上游 Skill，私用包额外收录 111 张原尺寸参考图。

## 验收边界

v20/v24 用于内容绑定和构图回归；自动候选仍需容量调整。30 图人工金标、学科专家盲评及线上生图供应商尚未完成实际验收。计划中的宿主 TS/DSH 接入按用户要求退出必需范围。高级视觉设计由 Codex 结合实际素材完成，自动母版不代表专家审美合格。
