# Figure Design 1.13.0 本机升级实施计划

## 目标和诊断依据

用户希望同一篇研究文章在独立会话中仍能交付可循着箭头阅读、能看见对象变化、能比较实验结果的技术路线图。1.11 的两次 DSH 冷启动都选择了文字读数。改变简报的主视觉和路径后，候选计划仍相同。固定最终计划和素材再次渲染，PNG、SVG 却逐次相同。优先改动简报到成图之间的步骤，同时补齐桌面插件只有参考索引、无法查看原图的问题。本地对照记录保存在 `outputs/2026-11-20-dsh-coldstart/验证报告.md`。

用户供图展示了平行记忆路径、方向纠错实例和实验比较三个阅读任务。同一机制可以有多种合适构图。验收看读者能否回答这些问题，避免把特定行数、配色或案例写成跨论文模板。

## 实施顺序

| 阶段 | 实施内容与交付物 | 验证方法 |
|---|---|---|
| 1. 构图 | 在 mixed 模式的普通 plan 入口消费主视觉、阅读顺序与路径的输入、中间交接物、输出；用户上传参考和已选参考位置优先。保留可编辑区域和原生连接。 | 固定 FigureContent，分别改变主视觉和路径，比较实际区域、坐标与边。以旧版 A、B 两份真实输入复跑。 |
| 2. 案例变化 | 将旧状态、核对依据、新状态、下一动作绑定到来源文字实例，或具体插图特征及所属对象；缺项列入待审。 | 在最终计划定位各标签与插图。检查错放、缺项及旧简报兼容性。目标宽度打开图片确认变化可见。 |
| 3. 定量证据 | 为有共同口径的读数提供分类横条和配对点图。行记录保存类别、条件、值和原文出处，图表记录指标、单位、基准、范围与读数或变化量。用同一记录画图、标数和登记素材。 | 通过正常 preflight/render 入口构图；核对负号、零、缺配对、混合单位和缺图。按原文检查比较条件、分母和结论。 |
| 4. 预检和渲染 | 设计绑定写入可编辑计划；显式传同一 brief 时核对内容指纹和承诺。质量报告给出实际区域、关系及需看图核对的条目。 | 原有测试、专门回归和 16 个基准案例全部通过。用两个空目录分别渲染相同输入并比较 PNG/SVG 字节。 |
| 5. 包和安装 | 私用 ZIP 含完整技能和 111 张原图，私用 DSH TGZ 复用该 ZIP；公开包只带允许公开的索引与资源。备份 Codex 用户安装和 DSH desktop 旧包，更新两个安装入口。 | 比对包内清单、版本、SHA-256 和实际安装目录。两个入口运行 doctor；检索五个候选并打开原尺寸文件。 |
| 6. 宿主冷启动 | 在两个 DSH 空白会话分别处理同一 Anthropic 原文；第三个 DSH 会话处理《The Tail at Scale》；再用独立 Codex 会话处理同一 Anthropic 原文。统一要求中文 mixed、PNG、SVG、离线 HTML 和质量报告。 | 只提供当前论文、技能内资源和解释器。保存首次产物、发生的修订及最终产物。逐图检查主路径、状态变化、定量比较、科学口径及显示宽度。 |

## 发布判定与恢复

代码、打包和宿主运行分别记录。每份图的视觉和科学判断对应其实际 PNG 与 render_hash。测试不替用户签署 accepted。性能对照使用原版的同篇两次盲测，异题仅用于检验迁移。四次运行不足以估计成功率。对可修复的部署与验收问题，先修复再验证。发生无法修复的安装或验收故障时，保留错误和生成物，用备份恢复两个宿主的旧安装，再分别运行 doctor 核实。

## 执行入口

在项目根目录运行 `make check`、`make test` 和 `make benchmark OUT=<新的验收目录>`。发布使用新的 DIST 目录运行 `make package-dsh-private DIST=<发布目录>`；此目标同时构建私用 ZIP。公开包通过 `make package package-dsh DIST=<发布目录>` 构建。各目录须保留已安装插件所引用的 TGZ。验收指标的数据结构和命令示例见[简报绑定与证据图](../../skills/figure-design/references/design-bindings.md)。
